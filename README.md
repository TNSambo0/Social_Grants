# Social Grants

**Social Grants** is a web application that simulates the services of **SASSA (South African Social Security Agency)**, allowing users to apply for social grants and understand the application process in a secure and interactive environment.

## Project Overview
The Social Grants application is designed to provide users with a realistic experience of applying for social grants. It helps users:
- Submit grant applications
- Track the status of their applications
- Learn about different types of grants
- Understand the eligibility criteria

This project is intended for educational and simulation purposes and is not an official SASSA system.

---

## Features
- User registration and secure login
- Grant application submission and management
- Application status tracking
- Admin dashboard to review and process applications
- Responsive and user-friendly interface

## Technologies Used

- **Backend:** C#, ASP.NET

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/TNSambo0/Social_Grants.git
2. Open the solution in Visual Studio.
3. Restore NuGet packages.
4. Build the solution.
5. Configure your SQL Server connection string in appsettings.json or the relevant configuration file.
6. Run the application.

---

## Usage
1. Open the application in your browser.
2. Register a new account or log in with an existing account.
3. Navigate to the "Apply for Grant" section.
4. Fill in the required information and submit the application.
5. Track the status of submitted applications via the dashboard.
